Step Functions orchestrates a stock-data pipeline in region ap-southeast-2: a Lambda named stock-data-available returns an S3 path, and when it does, Step Functions starts a Glue Spark job named stock-transformer that writes rows to a DynamoDB table. Package the Lambda zip and upload the Glue script and the sample CSV to S3 via Terraform so a single apply is self-contained. Wire the Lambda ARN, the Glue job name, and the DynamoDB table name into the state machine definition via templatefile.
